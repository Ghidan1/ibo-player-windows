# IBO Player for Windows — v1.0

مشغّل IPTV لسطح المكتب (Windows) — نفس فكرة IBO Player Pro: التطبيق نفسه **لا يحتوي على أي قنوات**، أنت تحمّل قائمة التشغيل الخاصة بك.

## طرق تسجيل الدخول

- **Xtream Codes API**: رابط السيرفر + اسم المستخدم + كلمة المرور — قنوات مباشرة + أفلام + مسلسلات + EPG.
- **رابط M3U**: الصق رابط قائمة `.m3u` — قنوات مباشرة، مع دعم EPG عبر رابط XMLTV من الإعدادات.
- **ملف M3U**: اختر ملف `.m3u` / `.m3u8` من جهازك.
- **MAC Portal**: يعرض معرّف الجهاز (MAC) الخاص بك لتسجيله عند مزوّد الخدمة — لا يلزم أي تفعيل مدفوع داخل التطبيق.
- **Demo**: خمس قنوات عامة مجانية للتجربة فورًا (العربية، الجزيرة، Red Bull TV، DW، Mux).

## المميزات

- **Live TV**: قائمة قنوات بالشعارات، تبديل سريع، بحث، مفضلة (★)، أحدث القنوات، EPG الآن/التالي.
- **Movies**: شبكة بوسترات بالعنوان والسنة والتقييم، بحث، تفاصيل، استئناف من حيث توقفت.
- **Series**: بوسترات، اختيار الموسم والحلقة، استئناف.
- **دليل البرامج (7 أيام)**: اختر قناة ويومًا، وشاهد البرامج؛ البرنامج الجاري يمكن تشغيله من البداية (Catch-up) إذا كان المزوّد يدعمه.
- **المشغّل**: تشغيل HLS عبر VLC، ملء الشاشة، الصوت، اختيار مسار الصوت والترجمة، نسبة العرض.
- **شاشة مزدوجة**: شاهد قناتين معًا جنبًا إلى جنب.
- **رقابة أبوية**: قفل فئات أو قنوات برقم PIN (الافتراضي 0000).
- **6 ثيمات ألوان**: بنفسجي، أزرق، أخضر، أحمر، برتقالي، تركوازي.
- **الإعدادات**: رابط EPG/XMLTV، حجم الـ Buffer، تسريع الأجهزة، تبديل قائمة التشغيل، تسجيلات محفوظة.

## التشغيل

- **المثبّت**: شغّل `IBOPlayer-Setup-1.0.exe` — يثبّت في مجلد المستخدم بدون حاجة لصلاحيات مسؤول.
- **أو مباشرة**: شغّل `IBOPlayer.exe` (ملف واحد مستقل، يحمل VLC بداخله).

## البناء

يُبنى تلقائيًا على GitHub Actions (Windows runner + .NET 8 + Inno Setup) من هذا المستودع.

## ملاحظات

- التطبيق يشغّل قوائمك القانونية الخاصة فقط. القنوات التجريبية المدمجة هي بثوث عامة مجانية.
- لم يُختبر بعد على جهاز ويندوز حقيقي — جرّبه أولًا على جهازك الشخصي.
