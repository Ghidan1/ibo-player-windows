# Zaghlol Player for Windows — v2.0

مشغّل IPTV لنظام Windows بواجهة تلفزيون داكنة عصرية — **التطبيق نفسه لا يحتوي على أي قنوات**، أنت تحمّل قائمة التشغيل الخاصة بك.

## طرق تسجيل الدخول

- **Xtream Codes API**: رابط السيرفر + اسم المستخدم + كلمة المرور — قنوات مباشرة + أفلام + مسلسلات + EPG.
- **رابط M3U**: الصق رابط قائمة `.m3u` — قنوات مباشرة، مع دعم EPG عبر رابط XMLTV من الإعدادات.
- **ملف M3U**: اختر ملف `.m3u` / `.m3u8` من جهازك.
- **MAC Portal**: يعرض معرّف الجهاز (MAC) الخاص بك لتسجيله عند مزوّد الخدمة — لا يلزم أي تفعيل مدفوع داخل التطبيق.
- **قنوات تجريبية**: 5 قنوات مجانية تعمل فوراً بدون اشتراك (العربية، الجزيرة، Red Bull TV، DW، بث تجريبي).

## المميزات

- بث مباشر: تصنيفات، بحث، مفضلة، شوهد مؤخراً، EPG (الآن/بعدين) ودليل برامج 7 أيام مع Catch-up (تشغيل من البداية) لاشتراكات Xtream.
- أفلام ومسلسلات: بوسترات، بحث، تفاصيل، مواسم وحلقات، استكمال من مكان ما توقفت.
- شاشة مقسومة: شغّل قناتين مع بعض (كليك يمين على قناة ← تشغيل في الشاشة الثانية).
- قفل أبوي: قفل تصنيفات بـ PIN (الافتراضي 0000، يتغير من الإعدادات).
- 6 ثيمات ألوان، ساعة حية، ملء الشاشة، أبعاد صورة، مسارات صوت وترجمة.
- الواجهة مبنية بـ WebView2 (Edge Chromium) مع تشغيل HLS عبر hls.js — وتعمل مع أي سيرفر IPTV.

## التشغيل

- **المثبّت** `ZaghlolPlayer-Setup-2.0.exe`: تثبيت لكل مستخدم بدون صلاحيات مدير، يضيف اختصاراً لقائمة ابدأ وسطح المكتب.
- **المحمول** `ZaghlolPlayer.exe`: ملف واحد يشمل كل شيء (يحتاج Microsoft Edge WebView2 Runtime — موجود افتراضياً في Windows 11).

## البناء
